# Interactive 360° Virtual Tour

An interactive web page designed to display 360° panoramic scenes using WebGL and the Three.js 3D library.

## 📌 About The Project
This project explores 3D WebGL rendering in the browser. It maps equirectangular images onto a 3D spherical space, enabling smooth user navigation, pan/tilt controls, and interactive elements inside a virtual space.

## ✨ Features
* **360° Scene Navigation:** Smooth drag-to-look camera rotation inside a 3D sphere.
* **Interactive Hotspots:** Clickable scene elements designed to trigger actions and information overlays.
* **Responsive Canvas:** Full-window WebGL canvas rendering.

## 🛠️ Built With
* JavaScript (ES6)
* Three.js Library
* HTML / CSS
